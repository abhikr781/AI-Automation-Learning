# Day 22 – AI Social Media Content Generator

## 📌 Project Overview

This workflow automatically generates platform-specific social media content using AI.

Instead of manually writing captions, hashtags, hooks, CTAs, and image prompts for every platform, AI creates optimized content tailored to the selected social media platform and target audience.

The generated content is ready for publishing or can be passed to an image generation workflow for creating marketing creatives.

---

## 🎯 Business Problem

Businesses and marketing agencies spend hours creating content separately for LinkedIn, Instagram, Facebook, and X (Twitter).

Every platform requires:

- Different writing style
- Different caption length
- Different hashtags
- Different engagement strategy
- Different posting schedule

This workflow automates the complete content creation process within seconds.
