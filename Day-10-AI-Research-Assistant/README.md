# 🤖 Day 10 - AI Blog Writer

## 📌 Project Overview

This project is an AI-powered Blog Writer built using n8n and OpenAI.

The user provides a topic, and the AI automatically generates a professional, well-structured blog article in Markdown format.

This workflow demonstrates how Large Language Models can automate long-form content generation for blogs, websites, newsletters, and marketing.

---

# 🚀 Features

- Generate complete blog articles
- Professional writing style
- SEO-friendly headings
- Introduction and conclusion
- Bullet points where required
- Clean Markdown output
- Easy to customize

---

# 🛠 Tech Stack

- n8n
- OpenAI Chat Model
- AI Agent Node
- Chat Trigger
- Respond to Webhook
