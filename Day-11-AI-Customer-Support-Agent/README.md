# 🤖 Day 11 - AI Customer Support Agent

## 📌 Project Overview

This project is an AI-powered Customer Support Agent built using n8n and OpenAI.

The workflow accepts customer queries and generates professional customer support responses in a structured format.

The AI automatically analyzes the customer's issue and provides:

- Priority
- Ticket Status
- Ticket ID
- Customer Sentiment
- Issue Summary
- Explanation
- Recommended Solution
- Estimated Resolution Time
- Next Steps
- Helpful Tips
- Professional Closing Message

This project demonstrates how AI can automate customer support workflows while maintaining professional communication.
